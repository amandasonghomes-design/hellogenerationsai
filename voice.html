AI 朗读

🔊 中文文字转语音

贴上文字，选一个声音，点“朗读”。免费，不用注册，文字不会上传。

// TIPS

🎙 哪个声音最自然？

⭐ 首选：Microsoft 晓晓（Xiaoxiao）

女声，温暖自然，像真人讲故事。适合灵修、故事、旁白。
在 Microsoft Edge 浏览器打开本页，下拉里会有 “Microsoft Xiaoxiao Online (Natural)”。

⭐ 男声：云扬（Yunyang）／云希（Yunxi）

云扬稳重，适合新闻和讲道；云希年轻亲切，适合轻松内容。

📱 苹果手机／平板

选 “婷婷 Tingting”“美嘉 Meijia”，或“增强版／优质版”（Enhanced／Premium）。到 设置 → 辅助功能 → 朗读内容 → 声音 → 中文，可下载更自然的版本。

🤖 安卓手机／Chrome

选 “Google 普通话”或“Chinese (Mainland)”开头的声音。

💡 听起来像机器人时：把语速调到 0.9 左右，每段文字短一点，加上逗号和句号，会更自然。
// MP3

💾 想存成 MP3 文件？

浏览器的朗读功能不能直接保存文件。要 MP3，用免费的 edge-tts ↗（Microsoft 的自然声音），在电脑上两步完成：

步骤 1 · 安装（只需一次，需要 Python）

pip install edge-tts

步骤 2 · 把文字存成 input.txt，然后运行

edge-tts --voice zh-CN-XiaoxiaoNeural --file input.txt --write-media output.mp3
