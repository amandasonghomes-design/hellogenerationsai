🤖 Muse 能做什么

Muse 被介绍为一个代码生成助手（coding agent）：能自动编写、修改、调试并部署代码。

🧱

生成完整网站

HTML / CSS / JS，或小型应用，一句话就能开始。

📦

创建、更新仓库（repo）

在 GitHub 新建或修改仓库（repo；需要你授权或提供 token）。

⬆️

推送代码

把写好的代码提交（commit）并推送到 GitHub。

🔑

帮你完成授权

通过 Composio 之类的连接器处理 OAuth 授权和 token 刷新。

⚠️ 以上是网上对 Muse 的介绍，具体功能请以 Meta 官方说明和你自己的试用为准。
// 02

📄 GitHub 怎么托管网站

GitHub Pages 可以免费托管任何静态网站（HTML、CSS、JS）。

📌 发布你推送的文件

GitHub Pages 会把你推送到仓库（repo）里的静态文件发布成网站。

🆕 新仓库或旧仓库（repo）都行

可以在新仓库，也可以在现有仓库里启用 Pages。

🏠 托管的网址

项目站点：用户名.github.io/仓库名
例如：amandasonghomes-design.github.io/angieartgallery/

🚀 推送就上线

推送 index.html、index.md 或 README.md 后，网站就能访问。

💡 因此：只要 Muse 把网站推到 GitHub，你在仓库（repo）设置里启用 Pages，网站就能公开访问。详细说明见 GitHub Pages 官方文档 ↗。
// 03

✅ 典型流程：六步上线

  1. 创建 GitHub 账号SIGN UP

    先到 github.com/signup 注册。可以用邮箱新建账号，也可以直接用 Google（Gmail）等账号登录。已有账号就直接登录。

  2. 连接 GitHubCONNECT

    让 Muse 连接你的 GitHub。它会引导你完成 OAuth 或 token 授权。

    先装 Muse 的 GitHub 应用：Muse 要先在你的 GitHub 里安装 Muse 应用（app），才能和 GitHub 对话。请对 Muse 说：“请给我一个链接，让我在 GitHub 上安装 Muse 应用（Muse app for GitHub）。”点开链接，选择你的账号和要开放的仓库（repo），按 Install / Authorize 完成。

    ⚠️ 这一步请在电脑浏览器里完成，手机上容易卡住或看不到授权按钮。
  3. 生成网站CREATE

    告诉 Muse 你要什么，例如：“创建一个带 hero 区和联系表单的简单 landing page。”
    （hero 区 = 页面最上方的大标题 + 按钮；landing page = 单页宣传网站）

  4. 推送到 GitHubPUSH

    例如：“把这个代码推到一个叫 landing-page 的新仓库（repo）。”

  5. 启用 PagesENABLE PAGES

    在 GitHub 打开仓库（repo） → Settings → Pages，选择要发布的分支和文件夹。

  6. 网站上线LIVE

    GitHub Pages 自动发布静态文件，几分钟后就能用网址打开。

// 04

💬 可以直接对 Muse 说

点“复制”，粘贴给 Muse 就能用。

PROMPT · 先装 GitHub 应用（用电脑）

请给我一个链接，让我在 GitHub 上安装 Muse 应用（Muse app for GitHub）。

PROMPT · 做网站

帮我做一个个人作品集网站。

PROMPT · 做 landing page（单页网站）

创建一个带 hero 区和联系表单的简单 landing page。

PROMPT · 推送到 GitHub

把这个代码推到一个叫 portfolio-site（换成你的项目名）的 GitHub 仓库。

PROMPT · 更新网站

更新首页并再次推送。

// 05

🔒 小提醒

⚠️ 授权要谨慎：授权后，工具可以修改你的仓库（repo）。尽量只开放单个仓库（repo）的权限，用完后到 GitHub 设置里撤销。
💡 想要更多功能：本站用的是 GitHub + Vercel（同样免费，还有访问统计）。GitHub Pages 更简单，适合第一次做网站。
